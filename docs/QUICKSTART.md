# ULTRON - Quick Start Guide

## 🚀 První Step: Setup

### 1. Instalar Dependencies:

```bash
npm install
```

### 2. Configurar .env (IMPORTANT!):

Crea `/.env` desde la plantilla o edita directamente:

```bash
# ULTRON - Configuration File
# Use this file for sensitive data only
# Git will NOT include changes to this file

# Ollama settings
OLLAMA_MODEL=qwen3.5:4b

# Claude Code directory
CLAUDE_CODE_DIR=~/.claude

# Permissions (MINIMIZe prompts to save tokens)
PERMISSION_MODE=auto

# Memory database
MEMORY_DB_PATH=~/.claude/mem/db.sqlite

# Sync token (optional but recommended)
MEMORY_SYNC_TOKEN=your-cmem-sync-token-here
```

## Running Ultron for the First Time

```bash
# Linux/macOS:
./scripts/run-ultron.sh

# Windows PowerShell:
.\scripts\start-ultron.cmd

# Or manually with TypeScript:
npx ts-node src/index.ts
```

## Project Version Management

### Check Current Version:

```bash
npm ls
# or view package.json version field
```

### Create a New Release:

```bash
# Update version number in package.json
nano package.json  # Change "0.1.0-beta" to "0.2.0" etc.

# Commit the release
scripts/create-release.sh <version>
# Example: scripts/create-release.sh 0.2.0
```
